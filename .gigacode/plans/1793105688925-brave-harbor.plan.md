## Файлы для создания/редактирования

### 1. `pyproject.toml`
- Python 3.11+
- Poetry-управление зависимостями
- Группы: main, dev, test
- Ruff-конфигурация
- pytest-конфигурация

### 2. `Dockerfile` (multi-stage, non-root)
- Stage 1: builder (установка Poetry + зависимостей)
- Stage 2: runtime (alpine, non-root user)
- Копируем только нужные файлы

### 3. `docker-compose.yml`
- Сервисы: db (PostgreSQL), api (FastAPI)
- volumes для данных БД и миграций
- healthcheck для db

### 4. `.gitignore`
- Python: __pycache__, .pyc, .egg-info, dist
- IDE: .vscode, .idea
- Env: .env, .env.*
- Docker: node_modules, staticfiles
- OS: .DS_Store, Thumbs.db

### 5. `README.md`
- Краткое описание проекта
- Стек технологий
- Архитектурная схема (ASCII)
- Инструкции по запуску (локально + Docker)
- Структура проекта

### 6. `tests/test_imports.py`
- Базовая проверка, что все модули импортируются без ошибок
- Проверка структуры папок

## Порядок выполнения

1. Создать все пустые папки и `__init__.py`
2. Написать `pyproject.toml`
3. Написать `Dockerfile`
4. Написать `docker-compose.yml`
5. Написать `.gitignore`
6. Написать `README.md`
7. Написать `tests/conftest.py` и `tests/test_imports.py`
8. Запустить `poetry install`
9. Запустить базовые тесты
10. Коммит: `chore: initial project setup with layered architecture`

## Верификация
- `poetry install` проходит без ошибок
- `pytest tests/test_imports.py` проходит
- `ruff check src/ tests/` не ругается
- `docker compose config` валидный
